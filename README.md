# Local Security Platform Lab

Kubernetes-native security platform built with:

- Falco (runtime detection)
- Trivy (image scanning)
- Syft (SBOM)
- OPA (policy)
- Cosign (image trust)

## Environments

- GCP (full execution)
- Rancher Desktop (enterprise constraints simulation)

## Goal

Reproducible pipeline:

git clone → run script → deploy → security platform up
